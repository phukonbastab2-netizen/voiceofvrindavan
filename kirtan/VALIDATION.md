# Stage-first validation

Local browser checks cover desktop and mobile viewports with the production content security policy:

- The 3D stage loads with an empty character configuration and makes no model requests.
- Three instrumental demos produce nonzero Web Audio analyser output after a play-button click.
- Track selection, pause/resume, volume, immersion, Escape and reduced motion work.
- Camera dragging and wheel zoom update the 3D camera.
- There is no horizontal page overflow, no script error and no failed default asset request.
- A supplied test GLB with named clips can be loaded through the optional configuration.
- A missing optional model shows a visible notice while stage and music remain available.

These are browser viewport checks, not a physical phone benchmark. Earlier character experiments were removed from this version after the owner chose to add their own models later. No finished character, costume or authentic dance reproduction is claimed.
