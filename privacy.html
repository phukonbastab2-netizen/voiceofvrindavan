Privacy &
permissions.

Phone tasks

You enable Android Accessibility yourself. During an active phone task, accessible screen text, app names, your task and recent action results are sent to the owner-operated backend and OpenAI. Password-marked fields are excluded, but other sensitive text can still appear on screen. Avoid running tasks on private screens you do not want shared. Stop ends the task and prevents pending actions from running.

Coding

AI coding requests include your instruction and current file. Drafts and saved files remain in app storage unless you export them. HTML and JavaScript previews block network and device file access.

Backend and storage

The OpenAI API key stays on the backend. Each installation receives a session token, stored encrypted on the device; the backend stores its hash and expiry. The test backend retains session and daily request counters, does not intentionally save task or screen contents to its state file, and sends OpenAI requests with storage disabled. This setting does not itself promise that a provider retains no operational or abuse-monitoring data.

Your choices

Use Stop to end phone control, disable the accessibility service in Android settings to revoke access, and clear the app's storage or uninstall to remove local drafts and the installation token. Previously exported files must be deleted separately. Installation sessions expire after 30 days.

Test-build limits

This independently developed app is not an official OpenAI or Codex application. The current AI connection depends on the owner's PC test server and a shared five-request daily limit. Android installation permissions and accessibility access are required for the relevant features. AI output may be incorrect; review important results.
