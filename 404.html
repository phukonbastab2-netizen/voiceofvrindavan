Early-access connection

AI currently runs through the owner’s test server. It works while that server is online, with a shared limit of five AI requests per day. Local editing and previews work offline.

  1. 01Download and open the APK on your Android device. Allow installation for the browser if Android asks.
  2. 02Open Code to try creating. For phone tasks, enable Voice of Vrindavan in Android Accessibility settings.
  3. 03Enter your task and accept screen sharing. Routine steps continue automatically; Stop is always available.
What can this early version do?

It can operate accessible app controls, open launchable apps, and edit or preview single-file HTML/JavaScript. Some apps do not expose usable screen controls. It does not include a terminal, Python runtime or APK compiler. AI can make mistakes.

What is shared with AI?

During phone tasks, accessible screen text and app names go to the owner’s backend and OpenAI. Password fields are excluded, but other private text may be visible. Coding requests include your instruction and current file. The API key is held by the backend, not embedded in the APK.
